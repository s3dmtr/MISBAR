# MISBAR — مِسبار

> منصة هجومية لاكتشاف الثغرات واستغلالها في **بيئة معزولة** وضمن **نطاق مصرّح به** فقط، مع بقاء القرار النهائي بيد **الفريق الأحمر البشري**.

المشروع الداخلي: **TEMPO**. المستودع: **MISBAR**.

---

## الفكرة باختصار

بدل قائمة ثغرات مبعثرة، يقدّم المنتج **المسار الأخطر** (Critical Attack Path) للوصول إلى الثغرة، مرتّباً بالأولوية، مع **دليل استغلال (PoC)** موثّق داخل بيئة معزولة — انطلاقاً من **الضلع الذي يحدّده العميل** بنفسه، قبل أن ينتقل كل شيء إلى **اعتماد الفريق الأحمر**.

**الخيط الرابط عبر الرحلة:** تفويض ← اكتشاف ← إثبات واعتماد.

---

## المبادئ الحاكمة (Guardrails)

- **لا فحص خارج النطاق المصرّح:** لا يبدأ أي اختبار إلا بعد رفع مستند التفويض الرسمي وتحديد النطاق.
- **بيئة معزولة:** الاستغلال وإثباته يتمّان داخل بيئة معزولة فقط.
- **إنسان في الحلقة:** لا تسليم نهائي دون **اعتماد بشري** من الفريق الأحمر.
- **حوكمة وانضباط أولاً:** الشرعية قبل القدرة التقنية.
